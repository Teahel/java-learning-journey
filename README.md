## 每日节奏
- 北京时间 18:00 接收 ChatGPT 自动学习课程。
- 每天 60–90 分钟：理论学习、动手编码、测验及总结。
- 每周日复盘，记录掌握情况和薄弱点。
- 练习代码中的 TODO 由自己动手完成。

> 自动课程推送不代表自动提交 GitHub。学习记录需要主动提交，或在聊天中请求协助提交。
