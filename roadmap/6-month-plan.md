# Java 工程师六个月进阶计划

开始日期：2026-10-15。建议每天 60–90 分钟；每日课程通过 ChatGPT 自动任务于北京时间 18:00 推送。

## 技能自评
| 技术 | 当前水平 |
|---|---|
| Java 17/21 与 JVM | 未学习 |
| Spring Boot 3/4 与架构 | 未学习 |
| MySQL、Redis、MQ | 能独立使用 |
| Docker、K8s、CI/CD | 了解 |
| Spring AI、RAG、MCP | 能独立使用 |
| Kafka、Flink、时序数据库 | 未学习 |

## 学习路线
1. 第 1 月：Java 17/21、线程、JVM、GC、性能工具。
2. 第 2 月：Spring Boot 3、IoC、AOP、事务、Spring Security、模块化设计。
3. 第 3 月：缓存一致性、MQ 可靠性、幂等、限流、分布式事务与压测。
4. 第 4 月：Docker、Jenkins Pipeline、Kubernetes、发布与监控。
5. 第 5 月：Kafka、TDengine 或 TimescaleDB、Flink 基础。
6. 第 6 月：系统架构、可观测性、Spring AI/MCP 与能源设备数据集成。

## 每日流程
- 15–20 分钟：阅读课程和理解原理
- 30–40 分钟：自己编写代码
- 10 分钟：每日测验
- 5–10 分钟：总结、打卡或提交笔记

每周日复习；不建议未经验证就升级旧生产项目。AI 工具调用须加入权限、参数校验和审计。

## 六个月目标
- 独立设计中型 Java 后端架构。
- 能依据 JVM、线程、SQL 和监控指标定位问题。
- 能完成 Java + 物联网 + AI 应用的开发、部署与排障。
