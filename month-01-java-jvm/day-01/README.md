## 知识点备忘
- `var` 不会让 Java 变成动态类型语言。
- `record` 自动生成构造器、访问方法、equals、hashCode、toString；字段引用不可重新赋值，但引用对象内部可能可变。
- Switch `case x ->` 不会发生传统分支意外贯穿。
- 文本块 `"""` 可改善多行 SQL 可读性。
